# Mess Management System
A PHP 8.3 + MySQL/MariaDB web application for hostel/mess money, meals, bazar, expenses, notices and room management.

## Stack
- PHP 8.3, PDO
- MySQL 8 / MariaDB
- Bootstrap 5.3 + Bootstrap Icons via CDN
- Chart.js + qrcode.js via CDN
- Session authentication, CSRF protection, password_hash()

## Local setup
1. Install PHP 8.3+, MySQL 8+, and VS Code.
2. Import `sql/schema.sql`.
3. Edit `config/config.php`.
4. Run `php -S localhost:8000 -t .`
5. Open http://localhost:8000

For a free online demo, see the deployment guide in the chat response.
